This item records a conjectural hierarchy for type C stable Grothendieck polynomials GC_\omega.

Expansion

For a signed permutation \omega, the predicted positive expansion is

GC_w = sum_{t in T_w} GQ_shape(t)

where T_w is the conjectural set of type C unimodal Hecke tableaux for w. The source note also gives a stronger GR-model formulation for GC_w^+.

Checked levels

The basic check compares Hecke words with pairs consisting of a type C unimodal tableau and a standard shifted set-valued tableau of the same shape.

The strong check imposes no adjacent equal Hecke letters and no consecutive entries in the same shifted set-valued tableau box.

The strongest check compares peaksets. The source note explains that this peakset-preserving level would imply the positive GQ-expansion.

Computer check

The script code/check_type_c_grothendieck.py is a combined curated checker for all three source scripts.

python code/check_type_c_grothendieck.py

The default run checks all three modes with max word length 4 and generator indices 0..3. These are bounded checks, not proofs.
