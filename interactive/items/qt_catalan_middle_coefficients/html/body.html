Let C_n(q,t)=\sum_D q^{area(D)}t^{dinv(D)}, with the sum over Dyck area sequences of length n, and put M=\binom n2.

Classical skeleton range

The Dyck-skeleton decomposition proves the following flat-middle statement. For n\ge 4 and 0\le d\le 2n-8, the coefficient of

q^j t^(M-d-j)

in C_n(q,t) is independent of j for every d\le j\le M-2d. The common value is the number of special Dyck skeletons of length n and deficit d.

The full flat-middle conjecture asks for the same independence throughout 0\le d\le \lfloor M/3\rfloor. That broader range is conjectural here.

Computer check

The script code/check_flat_middle_coefficients.py is a self-contained bounded checker ported from the Dyck repository. The default run checks n=4,\ldots,8, generating 2047 Dyck sequences, 25 (n,d) bands, and 325 middle-band coefficients.

python code/check_flat_middle_coefficients.py

The code is finite evidence and a regression guard. It does not prove the theorem or the full flat-middle conjecture.
