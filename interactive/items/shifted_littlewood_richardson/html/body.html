This item records conjectural shifted Littlewood-Richardson rules for skew shifted stable Grothendieck functions GP_{\lambda/\mu} and GQ_{\lambda/\mu}.

Rules

For the GP rule, sum over shifted set-valued P-tableaux of shape \lambda/\mu satisfying the lattice property:

GP_{lambda/mu} = sum_P GP_{wt(P)}

For the GQ rule, sum over shifted set-valued Q-tableaux satisfying both the lattice property and the primed-starting property:

GQ_{lambda/mu} = sum_Q GQ_{wt(Q)}

The source GQ script checks the related GR formulation, which the source README says implies the same GQ expansion.

Computer check

The script code/check_shifted_lr.py compares direct homogeneous monomial expansions with the expansions reconstructed from the conjectural rule.

python code/check_shifted_lr.py

The default run checks both GP and GQ/GR for degree 5, shape/skew [3,1]/[1], and 3 variables. These are bounded checks, not proofs.
