This item packages the finite computation used to complete Lemma 2 and Lemma 3 of Section 9 of Graham Hawkes's 2024 rational q,t-Catalan paper.

The source script is Conjectures-and-Computations/qt-catalan/qt-assisted.py. The curated script code/qt_assisted_2024.py preserves the source cutoff dstar=20 and the same position-coordinate m-Dyck path conventions, but gives a reproducible command-line summary.

The Lemma 2 check verifies a finite string-bound condition for the boundary paths selected by the source proof. The Lemma 3 check verifies, for every generated (m, ell) layer, that the positive monomial-string multiset equals the multiset of all generated path monomials together with the negative correction multiset.

The default run generated 5,692,942 records, checked 106 nontrivial Lemma 3 layers, and returned PASS for both Lemma 2 and Lemma 3.
