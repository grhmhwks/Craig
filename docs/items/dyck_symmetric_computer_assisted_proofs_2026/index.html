This item records finite computations used as proof components in the 2026 preprint on Dyck symmetric functions.

The code files are extracted from Appendix A and Appendix B. Appendix A contains the reusable Dyck-sequence routines and the routine that builds lower-half strings. Appendix B contains the finite checkers used in the local well-definedness proof: the small residual range, the seven-entry East/West window check, and the two finite checks used for the position-bound lemma.
