# Repository instructions

## Protected mathematical corpus

The entire `content/` directory is a read-only source corpus.

- Read and index files under `content/`.
- Never create, modify, rename, move, format, compile, or delete anything under
  `content/`.
- Never run a command whose output is written under `content/`.
- Generated indexes, caches, test data, and application outputs must be written
  outside `content/`.
- If a task appears to require changing `content/`, stop and report the conflict.

Application development belongs outside `content/`.
