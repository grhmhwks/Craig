# Combinatorics notes and computations

This folder contains a few of my conjectures and a few computations used in
various proofs.  It also contains summaries of the status of related problems
and, in some cases, minor new results.

## General structure

The material is organized into topic folders.  Each folder is intended to be
reasonably self-contained and normally includes:

- `explanation.tex`, which is the main entry point and describes the problem,
  definitions, known results, conjectures, current status, and the role of the
  other files;
- `code.py` and/or `code.cpp`, when computations, finite checks, examples, or
  data generation are useful;
- possibly additional TeX manuscripts, notes, tables, reports, data, or
  specialized proof materials.

The best way to approach a topic is to read its `explanation.tex` first and
then consult the accompanying code or supporting documents cited there.

The status of the material varies between folders.  Some files record proved
results, while others contain conjectures, computational evidence, proof
outlines, or work in progress.
